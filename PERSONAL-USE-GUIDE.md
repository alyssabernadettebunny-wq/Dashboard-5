# Cherry Brain — Personal Use

## First setup

1. Install Node.js if it is not already installed.
2. Double-click `BUILD-CHERRY-BRAIN.bat` once.
3. After it finishes, double-click `Open Cherry Brain.bat`.

## Normal use

Double-click `Open Cherry Brain.bat`. A browser window opens to the production build. You do not need Expo or Claude running.

Keep the small launcher window open while using Cherry Brain. Closing it stops the local production server, but does not erase your data.

## Backups

Open **Settings & Boundaries**, then choose **Export Cherry Brain Backup**. Store the downloaded JSON file somewhere safe, such as OneDrive.

Cherry Brain currently stores personal data in that browser on that computer. A backup is important before clearing browser data, changing browsers, reinstalling Windows, or moving to another device.
